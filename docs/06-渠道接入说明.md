# 渠道接入说明

CordiBank 通过渠道适配层把同一套银行智能体暴露给不同入口。所有渠道共用权限分级、注入防御与审计哈希链，消息留痕可在网页控制台右侧「渠道接入」卡与 `channel.hub.status` 回包中查看。

## 渠道一览

| 渠道 | 接入方式 | 状态 |
| --- | --- | --- |
| web | 网页控制台直连 RPC 与 SSE 流式 | 内置启用 |
| desktop | Windows 桌面壳内嵌同一控制台 | 内置启用 |
| openclaw（微信） | OpenClaw 网关 hooks 兼容入口，Bearer 令牌 | 配置后启用 |
| onebot（QQ） | OneBot v11 HTTP 上报，私聊与群聊 | 配置后启用（教程见 docs/07） |
| dingtalk（钉钉） | 企业内部机器人官方 HTTP 回调，sign 加签验签 | 配置后启用 |
| feishu（飞书） | 事件订阅官方回调，challenge 握手 + tenant_access_token 送回 | 配置后启用 |
| webhook（通用桥） | 通用 HTTP 上报，由桥接程序送回 | 即刻可用 |

> 说明：OpenClaw 是开源个人 AI 助手网关（非腾讯官方接口），其微信连接由网关侧桥接完成；微信个人号没有官方机器人 API，若需官方通道请使用企业微信或公众号，通过 webhook 桥接入。

## Webhook 桥（微信等通用桥）

桥接程序把用户消息 POST 到运行时，运行时同步返回智能体回复：

```bash
curl -X POST http://127.0.0.1:8123/channel/webhook/incoming \
  -H "content-type: application/json" \
  -d '{"channel":"wechat","from":"user-9527","text":"查询当前余额"}'
```

回包：

```json
{"ok":true,"result":{"ok":true,"channel":"wechat","from":"user-9527","reply":"当前余额 38642.50 元"}}
```

会话键为 `webhook-<channel>-<from>`，不同用户互不串话。回复由桥接程序负责送回原渠道。

## 微信（OpenClaw 网关 hooks 兼容入口）

1. 环境变量配置 hook 令牌：`CORDIBANK_CHANNEL_OPENCLAW_TOKEN=<你的令牌>`。
2. 上报地址：`POST http://127.0.0.1:8123/channel/openclaw/incoming`。
3. 鉴权：请求头 `Authorization: Bearer <令牌>` 或 `x-openclaw-token: <令牌>`（与 OpenClaw 官方 hooks 约定一致）。
4. 载荷：`{"message":"查询当前余额","name":"wx-alice"}`，`message` 必填。
5. 运行时同步返回 `{"ok":true,"reply":"当前余额 …"}`，由网关负责送回微信；会话键为 `openclaw-<name>`。

## 钉钉（企业内部机器人官方回调）

1. 钉钉开放平台创建企业内部机器人，接收消息模式选「HTTP 回调」，地址指向 `http://<公网或内网穿透>:8123/channel/dingtalk/incoming`。
2. 环境变量配置加签密钥：`CORDIBANK_CHANNEL_DINGTALK_SECRET=<机器人的加签密钥>`。
3. 运行时按官方算法验签：`sign = base64(HMAC-SHA256(appSecret, timestamp + "\n" + appSecret))`，时间偏差容忍 ±1 小时；验签失败返回 `ACCESS_DENIED`。
4. 回复走官方同步回包：HTTP 响应体即 `{"msgtype":"text","text":{"content":"…"}}`，无需额外调用发送接口；会话键为 `dingtalk-<staffId>`。

## 飞书（事件订阅官方回调）

1. 飞书开放平台创建企业自建应用，事件订阅请求地址指向 `http://<公网>:8123/channel/feishu/incoming`，订阅 `im.message.receive_v1`。
2. 环境变量：`CORDIBANK_CHANNEL_FEISHU_TOKEN`（事件订阅的 Verification Token，可选但建议）、`CORDIBANK_CHANNEL_FEISHU_APP_ID`、`CORDIBANK_CHANNEL_FEISHU_APP_SECRET`、可选 `CORDIBANK_CHANNEL_FEISHU_API_BASE`（默认 https://open.feishu.cn）。
3. URL 验证：运行时对 `url_verification` 事件原样返回 `challenge`（官方握手格式）。
4. 消息事件：进入银行 Agent 会话后，运行时用 `tenant_access_token`（`app_id`+`app_secret` 换取）调用官方 `im/v1/messages` 送回文本；群聊 @机器人 的占位符会自动剔除；会话键为 `feishu-<chat_id>`。

QQ 走 OneBot v11 社区协议（NapCat / Lagrange 实现），专门教程见 [07-QQ接入教程.md](07-QQ接入教程.md)。

## 安全约束

- 各渠道令牌 / 签名不匹配直接拒绝（`ACCESS_DENIED`），不进入智能体；OpenClaw 未配置令牌时入口整体关闭。
- 消息正文上限 2000 字符，超长截断；最近 50 条收发消息留痕。
- 所有渠道消息与回复经同一套注入防御（正则守卫 + 语义分类器）与审计哈希链，与网页入口一致。
